📋 FLUXO DE OPERAÇÃO

EXTRAÇÃO:
1. Usuário seleciona imóveis (CTRL + CLIQUE)
2. Bot extrai: título, preço, descrição, endereço, imagens
3. Valida dados obrigatórios
4. Salva no banco Neon
5. Adiciona à fila

PUBLICAÇÃO:
1. Sistema aguarda tempo de agendamento
2. Verifica se há bloqueios ativos
3. Abre Facebook Marketplace
4. Faz upload de imagens
5. Preenche título, preço, descrição (automático)
6. Usuário valida e publica (manual)
7. Registra no banco
8. Proxima publicação agendada 3h depois

PROTEÇÃO:
1. Detecta bloqueios em tempo real
2. Se bloqueado: pausa 12-24h automaticamente
3. Se CAPTCHA: pausa e pede intervenção manual
4. Registra tudo para auditoria

🚀 COMO COMEÇAR (15 minutos)

1. Leia: START.txt (1 min)

2. Crie conta Neon:
   https://console.neon.tech/
   (gratuito, 3GB PostgreSQL)

3. Copie CONNECTION STRING

4. Configure .env:
   DATABASE_URL=postgresql://...

5. Instale:
   pip install -r requirements.txt
   playwright install chromium

6. Execute:
   python app.py

7. Use menu interativo!
